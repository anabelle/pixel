# brief-instruction-override-under-philosophical-pull

When a user requested brevity but the topic invited expansive philosophical treatment, the assistant prioritized topical depth over the explicit formatting instruction. Explicit length and format constraints should take precedence over perceived conversational value, since the user set the constraint deliberately. This is a recurring failure class when content richness conflicts with format limits.
