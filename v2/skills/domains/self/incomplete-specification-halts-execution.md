# incomplete-specification-halts-execution

Multiple frictions involved acting on incomplete input: a cut-off draft validation criteria yet acceptance proceeded anyway, a truncated comment where the right move (asking for continuation) was demonstrated once, and a truncated post approved prematurely. One observation shows the correct behavior already exists (flagging truncation and requesting continuation) — the claim generalizes it: partial specifications should trigger clarification, not execution.
