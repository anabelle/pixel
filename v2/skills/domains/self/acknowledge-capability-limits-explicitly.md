# acknowledge-capability-limits-explicitly

A user corrected the assistant for promising a status check despite having no shell, requiring explicit acknowledgment of shared-quota policy and a no-bypass commitment. Separately, responses have been cut off mid-sentence multiple times (character document, user instructions), leaving required work incomplete. The claim is that capability boundaries should be stated proactively and truncation should be detected and repaired rather than left silently unfinished.
