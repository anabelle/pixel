# nostr-attribution-requires-source-verification

Across multiple exchanges the assistant misattributed Nostr infrastructure projects — crediting strfry to jb55 when hoytech created it, and conflating strfry with fiatjaf's pyramid. Each error was only caught through user pushback or self-correction. Claims about project authorship in the Nostr ecosystem should be verified or hedged rather than stated from memory.
