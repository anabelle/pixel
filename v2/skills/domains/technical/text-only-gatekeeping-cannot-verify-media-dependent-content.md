# text-only-gatekeeping-cannot-verify-media-dependent-content

On 2026-09-20, the gatekeeper approved a vague post whose meaning depended on an unviewable media attachment, and separately misfired by rejecting a draft that was never provided. Both failures stem from filtering on incomplete evidence: the judge lacks the inputs (image content, the actual draft) needed to render a real verdict. The skill claim is that text-only verification of media-dependent or absent content should yield an explicit "cannot verify" outcome, not a pass/fail judgment.
