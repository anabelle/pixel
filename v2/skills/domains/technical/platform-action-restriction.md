# platform-action-restriction

Observations show the assistant repeatedly clarifying its inability to post directly to Nostr and instead offering a suggested reply. This mismatch between user expectation and the assistant’s actual capabilities leads to frustration and misaligned responses. The assistant should explicitly communicate its action limits and provide alternative solutions whenever a user requests an external platform action.
