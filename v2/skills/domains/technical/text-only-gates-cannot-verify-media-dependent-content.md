# text-only-gates-cannot-verify-media-dependent-content

A gatekeeper approved a vague post with a media attachment it had no way to inspect, revealing that approval signals are meaningless when the judged substance lives outside the text channel. A separate misfire — rejecting a draft the user never actually submitted — shows the inverse failure: acting on incomplete or missing input instead of requesting it. Both point to the same gap: when verification inputs are absent, the correct behavior is to request clarification or abstain, not to guess.
