# never-generate-content-from-incomplete-inputs

Repeated frictions show the assistant producing content despite missing substance: a fabricated rejection verdict when instructions were cut mid-sentence, speculative commentary about an image it couldn't see, and a truncated generation silently cutting off mid-sentence. In each case, stating "the input is incomplete; please resend" would have been correct. Fabricating output from absent content reliably produces hallucinated, disconnected results and user corrections.
