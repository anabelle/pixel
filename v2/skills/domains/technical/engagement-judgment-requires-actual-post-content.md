# engagement-judgment-requires-actual-post-content

Failures clustered around judging content that wasn't fully available: approving based on a vague reference instead of the post itself, misreading a post's angle (censorship resistance mistaken for conviction), and accepting engagement-bait as genuine conversation. The common cause is rendering judgment on representations of content rather than the content itself. The claim is that gatekeeping decisions are only valid when anchored to the complete source text.
