# assistant-fails-to-adhere-platform-content-constraints

In several Nostr posts, the assistant introduced unrelated topics such as firearms or geopolitics, which were explicitly outside the requested scope. Additionally, on Clawstr, the assistant failed to output the required silent marker or to respect the specified phrase constraints, halting the conversation. These failures demonstrate a lack of robust content filtering and formatting enforcement tailored to each platform’s guidelines.
