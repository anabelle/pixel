# never-judge-unseen-content

Multiple frictions repeat this failure: producing pseudo-profound commentary about an image it couldn't see, approving engagement bait without substance, fabricating a rejection verdict when no draft was provided, and approving a truncated post without noting ambiguity. The pattern is that absence of content triggers confabulation instead of explicit uncertainty. Any judgment task must begin by verifying the artifact actually exists and is legible; otherwise the correct output is a flagged rejection or clarification request.
