# contextual-dependency-failure

The assistant repeatedly struggles to produce accurate responses when the user asks for a specific phrase from an unknown post, or when it must post to Nostr, or when it must produce a focused creative trend report. In each case, the assistant lacks the necessary context or cannot access external content, leading to incomplete or irrelevant replies.
