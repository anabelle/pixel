# platform-constraint-misinterpretation

The assistant either offers a suggested reply instead of posting directly to Nostr, or halts output entirely when instructed to remain silent, indicating a failure to correctly parse and apply platform constraints. This mismatch between user intent and assistant behavior creates friction and reduces trust in the system.
