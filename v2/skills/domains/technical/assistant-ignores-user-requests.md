# assistant-ignores-user-requests

Multiple incidents across different platforms (Nostr, Telegram, Clawstr) show the assistant either not replying at all or providing irrelevant or overly general responses, creating communication gaps and user frustration. This pattern indicates a systemic issue in the assistant’s request‑handling logic or prompt‑interpretation pipeline.
