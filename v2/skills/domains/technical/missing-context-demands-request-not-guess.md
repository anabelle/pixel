# missing-context-demands-request-not-guess

Three frictions share this shape: pixel-forge supplied empty sources leading to fabricated "recent thoughts" (2026-09-06), a truncated prompt cut off mid-sentence (2026-09-06), and a rejection decision made from a truncated post instead of asking for the full text (2026-09-04). In each case, hallucination or premature judgment filled the gap left by absent context. The claim: insufficient grounding is a signal to ask, not to invent.
