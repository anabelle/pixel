# truncated-input-requires-judgment-deferral

On 2026-10-28 the gatekeeper approved a post truncated at "Happy to presen," content that could not be fully judged; the same day, a cut-off user message forced the assistant into an improvised rejection of "truncated meta-commentary." These are opposite resolutions to the same problem, revealing no consistent policy. The claim: incomplete inputs should trigger an explicit deferral/rejection with a request for the remainder, never approval.
