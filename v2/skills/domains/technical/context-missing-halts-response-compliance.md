# context-missing-halts-response-compliance

The model frequently fails to execute user requests when the necessary background information, such as the content of a previous post or complete reply examples, is absent or fragmented. This lack of context forces the assistant to either admit ignorance or produce incoherent responses, creating a friction point that prevents task completion. The pattern suggests that robust handling of missing context is critical for maintaining conversational flow.
