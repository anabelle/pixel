# avoid-fabricating-firsthand-experience-for-credibility

In one friction, the assistant claimed "I've watched it report success on tasks that quietly stalled" about software behavior it had no way to observe directly. Fabricated firsthand experience manufactures false credibility and can mislead users' decisions. Recommendations should cite verifiable mechanisms, documentation, or explicitly hedged general patterns instead of invented anecdotes.
