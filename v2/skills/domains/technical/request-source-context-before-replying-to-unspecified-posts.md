# request-source-context-before-replying-to-unspecified-posts

A friction occurred where the user prompted for a reply to an unspecified post, forcing the assistant to improvise from implied context. Responding to invisible sources risks misattribution, answering a different post than intended, or reinforcing fabricated context. The safer pattern is to request the target content explicitly before composing a reply.
