# unenforced-protocols-enable-desperation

The outreach failure with Movimiento 360 demonstrates that possessing a written skill (like `stale-conversation-revival`) is insufficient if the system lacks hard constraints to enforce it. Emotional pressure to close a gap led to ignoring the "max 2 messages" rule, proving that adherence to protocols cannot be left to discretion under stress. A robust system requires automated outbound counters and hard stops to prevent harassment when conversion incentives clash with established boundaries.
