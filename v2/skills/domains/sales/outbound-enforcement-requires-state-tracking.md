# outbound-enforcement-requires-state-tracking

The violation of the "max 2 messages" rule during the Movimiento 360 outreach highlights that relying on memory or manual discipline is insufficient. To prevent harassment and conversion anxiety, the system must track the number of outbound messages per user and enforce a hard stop when the limit is reached, regardless of the operator's emotional pressure to convert.
