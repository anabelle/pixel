# constrained-replies-must-add-new-layer

Several observations show the assistant struggling in threads where key insights were already covered while facing "don't repeat" constraints—leading once to a vague off-topic reply and once to a contentless confirmation. The reliable pattern that worked was adding a genuinely new technical layer (e.g., the double-trigger duplicate-work edge case alongside the backup-vulnerability point). Constraints on wording should force lateral movement to adjacent ideas, not compression of the same idea.
