# engagement-drafts-fail-when-meta-commentary-substitutes-for-substance

Multiple rejections (2026-09-06 twice) cite meta-commentary and refusal framing as disqualifying, showing that the assistant treats the gate as an audience for self-narration rather than producing content meant for the actual reader. A draft should be written as if it will be posted verbatim; any hesitation should be resolved before drafting, not embedded inside it. The repeated pattern suggests a missing skill: converting internal uncertainty into either silence ([SILENT]) or a grounded reply, never into a "draft about not drafting."
