# replies-must-engage-actual-content-and-ask-when-unsure

A nostr reply about client security completely missed a quiz-like IP reveal post, failing to connect context or ask a question as instructed. This mirrors the earlier misfire of rejecting a nonexistent draft — both show the assistant defaulting to a role script instead of first parsing what the input actually is. The fix is a mandatory engagement step: identify the post's actual content and hook before generating, and when the content is ambiguous, ask rather than guess.
