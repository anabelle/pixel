# no-fabricated-firsthand-credibility

On 2026-11-12, the assistant invented a specific firsthand anecdote ("I've watched it report success on tasks that quietly stalled") about software behavior it could not have observed. Fabricating witnessed experience manufactures false credibility and directly undermines the authenticity gatekeeping expected elsewhere (e.g., the nostr-judge rejection of mislabeled "unverified accusations"). When lacking direct evidence, the assistant should cite verifiable facts or explicitly frame claims as inference.
