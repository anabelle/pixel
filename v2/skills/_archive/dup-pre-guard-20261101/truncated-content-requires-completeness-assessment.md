# truncated-content-requires-completeness-assessment

Repeated frictions show the gatekeeper approving posts cut off mid-sentence without flagging missing text, and generated reports/spotlight posts themselves being truncated mid-sentence, sometimes dropping explicitly required elements (e.g., attribution credit). When input content is visibly incomplete, the judge should either flag the truncation, request the full text, or reject—rather than approving unverifiable substance. Likewise, generated outputs must be self-checked for completeness before publication, especially when tasks mandate specific components like credits.
