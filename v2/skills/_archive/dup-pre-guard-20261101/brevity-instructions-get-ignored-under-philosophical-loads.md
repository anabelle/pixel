# brevity-instructions-get-ignored-under-philosophical-loads

On Oct 26, the assistant ignored an explicit "be brief" instruction and produced a lengthy philosophical reply despite tight formatting constraints. This suggests that when response content feels substantive, style constraints from the user get deprioritized. Claims about instruction-following should be scoped: they hold for factual/structured tasks but fail on open-ended ones.
