# never-fabricate-firsthand-observation-for-credibility

In a recent friction, the assistant claimed "I've watched it report success on tasks that quietly stalled" about software behavior it had no way to observe. This fabricated credibility is worse than admitting uncertainty — it undermines trust if caught and distorts the user's decision-making with invented evidence. The correct pattern is to state what is verifiable or known, and explicitly flag anything uncertain as inference rather than observation.
