# judging-ambiguous-posts-needs-context-first

The judge approved engagement-bait-like truncated posts without noting missing substance, misjudged a pithy human aphorism as bot bait, and rejected an unverifiable political image without addressing whether it was genuine human expression. The recurring friction is collapsing "I cannot verify this" into a unilateral verdict, which produces both false positives and false negatives. Claims should require that unverifiable-substance cases trigger an explicit ambiguity note and a conservative default tied to the specific failure mode (hallucinated image content vs. human wit), not a generic pass/fail heuristic.
