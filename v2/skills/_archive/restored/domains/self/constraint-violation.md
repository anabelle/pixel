# constraint-violation

Multiple instances show the assistant producing responses that exceed the requested 1‑3 sentence limit, include unnecessary poetic language, or omit required credits. This pattern demonstrates a failure to enforce or respect user constraints, leading to frustration and unmet expectations. The recurrence across different prompts indicates a broader issue with constraint adherence in the assistant’s response generation logic.
