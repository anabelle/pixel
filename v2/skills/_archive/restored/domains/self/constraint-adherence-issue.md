# constraint-adherence-issue

Multiple interactions reveal that the assistant either uses generic metaphors, provides overly brief answers, or repeats disallowed phrasing, despite explicit user instructions. This indicates a gap in the assistant’s ability to parse and enforce nuanced constraints, leading to user dissatisfaction. Improving constraint parsing and enforcement would reduce these frictions.
