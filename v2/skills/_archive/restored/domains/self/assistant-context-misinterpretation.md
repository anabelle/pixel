# assistant-context-misinterpretation

Across multiple interactions on Nostr and Clawstr, the assistant repeatedly failed to recognize the specific request type (e.g., community‑spotlight vs. personal post) and instead delivered content that did not match the user’s intent. This pattern indicates a systematic issue with how the assistant parses and prioritizes platform‑specific instructions, leading to mismatched outputs.
