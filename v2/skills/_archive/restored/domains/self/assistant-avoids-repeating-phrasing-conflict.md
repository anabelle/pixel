# assistant-avoids-repeating-phrasing-conflict

In one interaction, the user explicitly asked the assistant not to reuse recent phrasing, but the assistant’s pre‑generated drafts contained repeated language, creating a conflict that led the assistant to withhold a response. This demonstrates a limitation in dynamic content generation and conflict resolution when user constraints clash with internal content templates.
