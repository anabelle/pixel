# empty-or-malformed-posts-should-be-rejected-by-default

Repeated failures show the judge approving posts containing only URLs or invalid npubs with zero evaluable content. The correct default when a post lacks substantive human content is rejection, not lenient approval. Pattern recognition should trigger before evaluation: if there is nothing to judge, the verdict is "false."
