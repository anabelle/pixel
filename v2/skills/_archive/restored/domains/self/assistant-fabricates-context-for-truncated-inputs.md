# assistant-fabricates-context-for-truncated-inputs

On Oct 17–18, the assistant replied to a post cut off mid-word by referencing an invisible "tool list," mischaracterized an image it had no context for, and a judge rejected a draft that was never actually present in the conversation. In each case the correct behavior was to flag the incomplete input rather than reason over hallucinated context. A rule requiring explicit acknowledgment of missing/truncated content before evaluation would prevent confident fabrication.
