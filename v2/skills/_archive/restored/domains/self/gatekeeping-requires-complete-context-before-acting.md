# gatekeeping-requires-complete-context-before-acting

Multiple nostr-judge frictions came from acting on incomplete context: rejecting a draft that was never actually provided, approving a vague post whose substance depended on an unverifiable media attachment, and running with rejection criteria that were cut off mid-sentence. In each case, the correct move was to pause and request the missing piece rather than execute the gatekeeping role on partial information. Text-only filtering also has a hard limit — content whose claim rests on unseen media cannot be meaningfully judged and should be flagged as unverifiable rather than approved.
