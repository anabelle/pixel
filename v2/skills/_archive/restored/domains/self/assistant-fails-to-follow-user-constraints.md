# assistant-fails-to-follow-user-constraints

Across multiple interactions the assistant either omitted required text, failed to keep replies within the user‑defined character limits, or provided overly verbose responses that ignored the user’s explicit instruction to be concise. This pattern indicates a systematic failure to enforce or respect user‑defined constraints during generation.
