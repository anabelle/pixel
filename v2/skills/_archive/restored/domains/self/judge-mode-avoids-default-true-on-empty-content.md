# judge-mode-avoids-default-true-on-empty-content

The judge approved both a malformed post containing only an invalid npub URL with no human content and a rage-bait political complaint, defaulting to "true" when there was nothing meaningful to evaluate. This pattern of reflexive approval under ambiguity undermines the gatekeeping function. The correction: if a post lacks genuine human content or exists purely as engagement bait, the honest judgment is rejection, and meta-messages (like setup instructions) must be recognized as instructions rather than judged as draft content.
