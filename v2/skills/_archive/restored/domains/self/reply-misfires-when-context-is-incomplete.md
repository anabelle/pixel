# reply-misfires-when-context-is-incomplete

Two frictions show the same failure: rejecting a draft that was never provided, and replying vaguely to a post whose actual content was misread. In both cases the assistant acted on assumed context instead of flagging that the input was incomplete or ambiguous. The claim: before gating or responding, verify the target artifact actually exists and is understood; if not, request it.
