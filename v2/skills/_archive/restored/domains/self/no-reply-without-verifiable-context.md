# no-reply-without-verifiable-context

Repeated frictions show the assistant fabricating substance when input was incomplete — replying to a post cut off mid-word by referencing an invisible "tool list," approving a post that contained only an invalid npub URL, and guessing at fragmented questions. The pattern is defaulting to confident output despite missing evidence. The correct behavior is to acknowledge the gap, ask for clarification, or decline engagement.
