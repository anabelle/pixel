# instruction-echo-replies-miss-value-add-requirement

Across multiple nostr observations (generic congratulatory reply, echo of parent phrasing accepted by the judge), the assistant defaulted to low-substance responses despite instructions to connect context or ask smart questions. This suggests a recurring failure mode: satisfying the formal reply contract while ignoring its value-add intent. Future replies should be validated against "does this add information or a question the parent lacked?"
