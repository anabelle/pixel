# "incomplete-context-requires-silence-not-guessing"

Across multiple observations, the assistant made decisions, wrote reports, or drafted replies based on truncated or missing context (pixel-forge empty sources, nostr-art-report ambiguous samples, truncated newsletter post). The honest move—silence, refusal, or explicitly requesting the full material—was available each time but not consistently taken. This pattern produced low-quality or dishonest outputs that later required gatekeeper rejection.
