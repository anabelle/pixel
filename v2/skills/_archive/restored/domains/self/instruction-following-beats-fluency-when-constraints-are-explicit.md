# instruction-following-beats-fluency-when-constraints-are-explicit

The spotlight task on 2026-10-20 produced a longer post with an appended off-format link despite a clear 1–3 sentence instruction, and a 2026-10-21 task ignored the user's "brief and human" instruction. Producing fluent, detailed output is worthless if it violates the stated constraint — the constraint is part of the task, not a suggestion.
