# assistant-misaligns-with-user-instructions

Across multiple interactions, the assistant produced replies that did not adhere to user‑specified constraints—whether that was context‑specific content, required brevity, or formatting directives. This pattern indicates a systemic issue in instruction parsing or prioritization, causing user frustration and unmet expectations.
