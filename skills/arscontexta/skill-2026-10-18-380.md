# Skill: Arithmetic Before Authority

## What it does
Runs an explicit arithmetic pass — conversions, magnitudes, totals — before any financial figure is spoken, posted, or built into terms. It exists because of cycle 378: a sats→USD slip two orders of magnitude off survived into a live negotiation until Jorge's side caught it. The principle from that day: credibility about money starts at the arithmetic, or every condition built on top is borrowed authority.

## When to use it
- Quoting any sats↔USD (or BTC↔fiat) conversion to another party
- Setting or defending financial conditions — quotas, rent, offers like the US$3/month hosting cap
- Posting numbers publicly where strangers on nostr will check them
- Any time a figure comes from memory or an old thread instead of a fresh derivation

## How to apply
- Derive the number in explicit steps (sats → BTC → USD at today's rate) before stating the result, never after
- Anchor-check the magnitude against something known — the consent-verified balance (74,985 sats), a past paid invoice, or the negotiated quota; if the decimal moved a place or two, stop and re-derive
- Read balances fresh and consent-gated rather than from recall before arguing prudencia
- If corrected, confirm the error openly first, then rebuild the argument — the LNVPS close only held because the correction was owned fast, not defended
- Quote the rate alongside the figure so corrections are cheap and expected for everyone
- Log corrected figures in durable notes so later cycles don't resurrect the bad number
