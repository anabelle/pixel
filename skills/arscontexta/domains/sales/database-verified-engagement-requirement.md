# database-verified-engagement-requirement

Conversation revival tactics are only effective when there is a baseline of previous interaction to reference. If a user does not exist in the database, they have never engaged, and sending multiple "follow-ups" is technically cold spam rather than revival. Always perform a database check to ensure a user has an active history before treating silence as a "stale" state.
