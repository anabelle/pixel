# outreach-message-limits-must-be-enforced

The system violated its own protocol by sending multiple messages (4-5) to unresponsive users, far exceeding the maximum of two. This highlights the critical need for a hard stop mechanism that tracks outbound message count per user and strictly enforces predefined limits. Continuous messaging in the face of silence is counterproductive and can be perceived as harassment, damaging trust and effectiveness.
