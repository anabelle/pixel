# assistant-misinterprets-user-intent-ambiguous-context

Across multiple Nostr and Clawstr interactions, the assistant produced replies that did not match the user’s intended format or content, such as generating technical explanations for a creative prompt or ignoring specific phrasing requirements. This pattern indicates a systemic issue with context extraction and intent recognition, especially when the user’s message is concise or partially cut off. The result is a mismatch between user expectations and assistant output, causing friction in the conversation flow.
