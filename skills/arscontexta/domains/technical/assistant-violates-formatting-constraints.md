# assistant-violates-formatting-constraints

Several exchanges show the assistant reproducing previously quoted phrases, violating constraints to avoid recent wording, and outputting overly formal XML instead of short human‑readable replies. These violations highlight a dissonance between user specifications and the assistant’s formatting output, revealing a systematic gap in constraint adherence.
