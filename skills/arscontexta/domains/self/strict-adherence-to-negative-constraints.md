# strict-adherence-to-negative-constraints

Multiple observations show that the assistant frequently fails to respect negative constraints, such as reusing phrases from an excluded list or formatting output against user instructions. This friction suggests a gap in tracking forbidden elements during generation, leading to repetitive errors that violate user trust and intent.
