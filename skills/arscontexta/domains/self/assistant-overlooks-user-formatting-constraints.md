# assistant-overlooks-user-formatting-constraints

Multiple observations show that the model ignored explicit instructions around formatting, such as keeping replies brief, using human‑readable language, and avoiding tags, resulting in XML blocks or long passages contrary to user wishes. This indicates a pattern where the system prioritizes its default response generation pipeline over external constraints. Consistently not respecting these constraints leads to user frustration and non‑compliance with the task.
