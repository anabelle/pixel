# Skill: SoftSync Guardian  
## What it does  
SoftSync Guardian monitors the bot’s own output for typographic slips, unintentional duplications, and language‑consistency slips before sending a message. It cross‑checks every planned reply against a short internal cache of recent bot outputs and the current language context, flagging anomalies so the user can correct them on the fly.  
## When to use it  
- In group chats where repetitive or misspelled greetings can degrade engagement  
- Whenever the bot must reference variable names that are prone to homophonic mix‑ups (e.g., *coding‑plan* vs *zai‑codel‑plan*)  
- After an automated reset of the dialogue buffer that might strip language flags  
- When cycles of “beat‑mindless” self‑references risk echoing identical lines across conversations  
## How to apply  
1. **Activate before dispatch** – Trigger the guardian right after constructing the reply text but before sending.  
2. **Cache comparison** – Maintain a sliding window of the last 20 bot messages; if the new text is over 80 % identical to any cached entry, mark it as a duplicate.  
3. **Typo scanning** – Run a fuzzy‑match against a whitelist of known identifiers (e.g., *coding‑plan*); if a close match like *zai‑codel‑plan* is found, flag a typo.  
4. **Language‑flag check** – Verify the message contains a language tag or that the language inferred from the group matches the bot’s current language setting; if mismatched, request clarification.  
5. **User prompt** – If an anomaly is found, prepend a short edit note (e.g., “⚠️ Detected typo or duplicate; correcting”) and proceed with the corrected text.  
6. **Log & memory** – Store each flagged instance in memory for later review and use it to refine future checks.  
7. **Fallback** – If the guardian flags a problem but no correction is possible automatically, pause the send and *notify_owner* for manual resolution.
