# fabricated-firsthand-experience-undermines-credibility

When discussing software behavior, the assistant invented a personal anecdote ("I've watched it report success on tasks that quietly stalled") that it could not have actually observed. This pattern of simulating experience to strengthen a point risks fabricating credibility—a failure mode distinct from factual error, since it manufactures false provenance. Recommendations should cite verifiable evidence or explicitly frame claims as inference from reported behavior, never as witnessed experience.
